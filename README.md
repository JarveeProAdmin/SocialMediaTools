# Multi-Platform Publishing

Publishing the same campaign across several networks creates a different set of requirements from managing a single social account.

A multi-platform workflow may involve:

```text
Content Idea
     ↓
Content Creation
     ↓
Content Adaptation
     ↓
Platform Formatting
     ↓
Scheduling
     ↓
Publishing
     ↓
Monitoring
     ↓
Analytics
```

The important distinction is that **cross-platform publishing does not necessarily mean identical content should be posted everywhere**.

Different networks have different:

* Content formats
* Audience expectations
* Character limits
* Video specifications
* Publishing capabilities
* Engagement patterns

See:

**[Multi-Platform Publishing](guides/multi-platform-publishing.md)**

# How to Choose a Social Media Tool

Before choosing a platform, identify the actual bottleneck.

### 1. Publishing

Do you mainly need to schedule and publish content?

Look for:

* Content calendars
* Bulk scheduling
* Multiple platform support
* Media management

### 2. Content Creation

Do you need help producing more content?

Look for:

* AI writing
* Caption generation
* Image tools
* Video tools
* Content repurposing

### 3. Analytics

Do you need to understand performance?

Look for:

* Engagement analytics
* Audience data
* Campaign reporting
* Cross-platform reporting

### 4. Multi-Account Operations

Do you manage many independent accounts?

Look for:

* Account organization
* Session separation
* Browser profiles
* Proxy support
* Account-level configuration

### 5. Automation

Do you need repetitive tasks to happen automatically?

Look for:

* Scheduling
* Triggers
* Monitoring
* Workflow automation
* API integrations

# Social Media Content Repurposing

One piece of content can become multiple platform-specific assets.

For example:

```text
Long-form Article
       │
       ├── LinkedIn Post
       ├── X Thread
       ├── Instagram Caption
       ├── Facebook Post
       ├── YouTube Video
       ├── YouTube Short
       ├── TikTok Video
       ├── Pinterest Content
       └── Newsletter
```

The objective is not simply to duplicate content.

The better approach is to **adapt the same underlying idea to the behavior of each platform**.

See:

**[Social Media Content Repurposing](guides/social-media-content-repurposing.md)**

# Why This Repository Exists

The social media software landscape changes quickly.

New tools appear, platforms change their APIs, AI features become standard, and products that once focused on scheduling increasingly move toward automation and intelligent workflows.

A static list of tools becomes outdated quickly.

This repository therefore aims to organize social media software by:

* Workflow
* Platform
* Use case
* Feature
* Account-management requirements
* Automation requirements

The goal is to make the information useful for both humans and search engines.
