# Social Media Analytics Tools

Social media analytics tools turn publishing activity into measurable information.

## What Analytics Should Answer
- Which content gets attention?
- Which platforms produce meaningful engagement?
- Which formats perform best?
- When is the audience active?
- Which campaigns are worth repeating?
- Where is content underperforming?

## Common Metrics

Depending on the platform, analytics may include impressions, reach, views, likes, comments, shares, saves, clicks, engagement rate, follower growth, and conversions.

Metrics should be interpreted in context. A large reach number is not necessarily valuable if the audience is irrelevant.

## Cross-Platform Reporting

Central dashboards improve operational visibility, but platform metrics are not always directly comparable. When precision matters, verify definitions in native platform analytics.

## Choosing Analytics Software

Prioritize metrics connected to your goal: awareness, engagement, video performance, traffic, or conversions.
